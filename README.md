# 550W AI Controller V4.6 Beta

当前 V4.x 系列均属于 Beta 测试版本，主要用于功能验证、动画调整、Bug 修复和正式发布前的稳定性测试。Beta 版本号用于开发与测试记录；首个公开正式版本计划从 V1.0.0 开始。

## 使用

1. 如果旧版 550W 正在后台运行，先从旧版 550W 托盘菜单选择“退出”。
2. 完整解压 `550W-AI-Controller-V4.6-Beta-Portable.zip`，保持目录结构，运行 `550W-AI-Controller.exe`。
3. 在“应用管理”中添加或选择应用，修改后“保存并应用”。“关于”可查看完整 Beta 更新日志并导出故障诊断包。

支持 Windows 10/11 x64。便携包包含 .NET 运行时；动画需要本机已安装的 Microsoft Edge WebView2 Evergreen Runtime。可选离线语音需要 Microsoft Visual C++ v14 x64 运行库，无可用语音引擎时静默继续。

## 三个开场时间参数

| 设置 | 作用 | 无历史配置时的默认值 |
| --- | --- | --- |
| 中央粒子待机时长（毫秒） | 从粒子首次显示开始，轻微动态待机多久 | 350 |
| 粒子 → 550C 总时长（毫秒） | 从粒子首次显示到 550C 完整形成，包含待机时间 | 1200 |
| 550C 完整停留时长（毫秒） | 550C 完整形成后，到开始全屏打碎的时间 | 450 |

重组时间 = 总时长 − 待机时长。总时长必须大于待机时长；无效组合会显示中文提示并阻止保存，不会偷偷修改输入。

例如待机 500ms、总时长 1000ms、完整停留 450ms：0～500ms 轻微待机，500～1000ms 重组，1000ms 完整形成，1450ms 开始打碎。三个时间继续受已有整体时间倍率统一缩放；上述示例以倍率 1 为准。

旧配置自动把原待机 A、原重组 B 转换为待机 A、总时长 A+B，完整停留保持原值。迁移按字段是否存在判断，重复保存或重新打开不会重复相加。旧重组字段仅保留配置兼容用途，不再作为独立的运行参数或界面入口。

## 当前启动流程

纯黑背景与现有中央粒子首帧 → 粒子轻微动态待机 → 重组成原版 550C → 550C 完整停留 → 全屏粒子扩散 → 原多窗口 HUD → 压缩并淡出交接真实应用。

计时从原生覆盖层实际绘制粒子的时刻开始，网页接管沿用同一时钟。WebView2、字体、音频与后续资源准备不会重新开始待机计时；准备期间原生画面继续按这三个参数推进。原始 550C SVG 的图形缓存与目标数据随主题打包，避免运行时重复解析采样。

启动不再展示定位点、激光、扫描线、机器人或机器人文字。后续粒子参数、全屏打碎时间、多窗口交叉显现、就绪停留和最终交接参数保持有效。

## 设置与兼容

左侧“动画”“声音”是全局默认模板；单应用可选择“跟随全局设置”或“使用独立设置”。三个时间参数同步支持全局、独立设置及批量应用；批量应用只复制通用配置，应用身份和启动目标保持独立。保存后的值用于下一次动画。

配置位置仍为 `%LOCALAPPDATA%\550W AI Controller\settings.json`。开发验证使用隔离配置，没有修改真实用户配置、自启动项或目标应用文件。

优化快捷启动、优化关闭、应用监听、诊断和主界面结构沿用上一版。主音效、语音和静音继续独立生效；缺失文件静默继续。默认资源不含电影原声或演员录音。

- 修正问号提示的 WPF 属性冲突，正常悬停不再触发“操作未完成”通知。真正异常的提示与诊断导出保留。

原时间参数、微动、550C、网页粒子/HUD/预加载、应用检测和快捷启动保持。检查没有反复抢占真实桌面。
