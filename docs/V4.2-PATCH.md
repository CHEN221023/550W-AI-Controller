# V4.2 扫描入场专项补丁 · 4.2.0

发布日期：2026-10-02。基于 V4.1 的小范围修补。

## 本次实际修改

- 纯黑背景；四个红色定位点位于等比逻辑画布的 24%/76%、13%/87%，不贴物理屏幕边角。颜色固定 #FF3B3B，辉光仅限点与细线附近。
- 四束激光逐渐伸向机器人上方/下方的四个独立端点，不再射向同一个中心点；左右半横线向内连接，形成完整的上下横线。
- 横线初始在图像上下边界外 10px，宽 350px；随后上横线向下、下横线向上同步移动。斜线端点始终连接相应横线。
- 同一个进度同时控制横线位置和图片上下两个显现区域，已扫描部分保持可见，未扫描中间区域保持透明。完整显现后立即隐藏所有扫描点、斜线、横线，再接入原镜头点亮、文字与粒子流程。
- 核心阶段总时长仍使用现有 CoreHoldMs × DurationMultiplier。仅在核心内部按 32%/43% 分配激光结构形成/双向显现，其余 12%/5%/8% 镜头、文字、停留不变；没有固定最低扫描时长。首个可绘制帧开始计时，避免首帧准备延迟跳过扫描起步，之后所有阶段仍使用原连续时钟。
- 原生预加载首帧只显示同位置的四个点，移除旧的固定 250ms 向中心发射线段；覆盖顺序和窗口交接逻辑没有改变。
- 版本号与现有更新日志升级至 V4.2，未增加声音功能或改动原音效。

## 保留内容

原机器人 PNG 完全未修改：SHA256 `51a26921618ac45089320b03ed1ae3bc76538bfbca5709ecd1fa4f18266d833c`。

粒子准备、池和绘制函数与 V4.1 相同，默认仍为 700 个粒子、同一个 1920×1080 画布。原 550C 路径、HUD、主界面、设置逻辑、应用管理、声音、日志诊断和窗口交接保持。设置界面唯一文字变化是版本标记 V4.2。

## 针对性验证

最终三项离屏检查通过：

1. 四点位置、固定红色、四个独立激光终点、上下横线接合、同步向内扫描、遮罩边界与线坐标一致、扫描完成清理。1920×1080 和 1600×1000 坐标检查通过。
2. 截图像素检查：扫描早期机器人顶部和底部已有像素；尚未扫描的中间区域与外围背景像素均为纯黑。6 张关键帧位于 `docs/images-v42/`。
3. 实际播放验证：短设置 500ms 实测 496ms；长设置 1600ms × 1.5 实测 2396ms。随后粒子 → 550C → 粒子扩散 → HUD 顺序通过；保留 700 粒子、47 个节点和 9 个原有窗口。没有脚本异常或看门狗超时。

首次短时长检查发现首帧晚到会消耗扫描时间，针对该问题调整计时起点并复验。未重测无关模块，未打开真实目标应用，未做全屏桌面测试。

Controller 与 Animation 已完成 win-x64 自包含 Release 编译，文件版本 4.2.0.0；启动器与语音工作进程按已有脚本编译。压缩包 CRC、SHA256 和主题文件一致性检查随交付生成。

本次验证范围为前端离屏扫描和 Release 构建，不代表重新完成原生 WebView2/真实目标程序覆盖验收。V4.1 的原生运行环境限制记录保留在历史报告中，本补丁没有修改该运行链。
