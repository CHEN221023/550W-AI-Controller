# V4.3 Beta 收尾补丁

日期：2026-10-02。产品版本 `4.3.0-beta`，Windows 文件版本 `4.3.0.0`；四段文件版本格式不代表正式发行。

## 本次修改

- 真正移除启动状态机中的扫描定位、激光、上下扫描、机器人显现、点亮、文字、停留和机器人粒子化阶段。不是把旧阶段时间设为零。
- 第一个有效状态为 `PARTICLE_RESIDUE`，直接使用原有中央粒子位置、颜色、大小和运动。保留 `LOGO_ASSEMBLING → LOGO_HOLD → LOGO_BURST → MULTIWINDOW_REVEAL → MULTIWINDOW_ACTIVE` 与最终交接。
- 停用启动时的机器人图像读取、解码、纹理采样和原生预热。原生准备画面只保留不透明纯黑背景；没有更改覆盖、置顶和交接生命周期。
- 停用只属于前置阶段的 `POWER_ON` 音效与 `CORE` 语音，移除声音测试、主题预载映射及相关选择项。保留 550C、HUD 与关闭声音。
- 全局和单应用的动画控件均移除核心阶段时长、核心粒子化时长、核心图像选择及失效说明。有效粒子、550C、HUD 和交接参数保留，分组改为“中央粒子与 550C”。应用发现/兼容轮询不属于视觉扫描，未删除。
- 界面与产品元信息明确为 V4.3 Beta；日志从 V4.2 Beta 开始，其七条原文保持，新增 V4.3 Beta 与顶部 Beta 版本说明。
- 当前 README 改为准确的现行使用说明；旧补丁报告作为历史记录保留。

旧机器人资源和配置字段保留，启动流程不再使用。关闭动画保留原行为；应用管理、继承/覆盖架构、快捷启动和诊断架构未变。

## 一次针对性验证结果

- 两项前端检查均首次通过。比较 V4.2 与 V4.3 Beta 的六个对应时刻：中央粒子起点、粒子中段、550C 重组、Logo 完整停留、全屏扩散、HUD 交叉显现；粒子画布像素和原 550C 渲染缓存校验完全一致。
- 实际网页完整播放首次通过：无扫描/机器人节点，无机器人资源请求，无废弃音效请求，无旧核心状态；旧核心时间故意设置为 10000ms 也没有延长启动。700 粒子、47 HUD 节点、9 个原窗口及最终交接正常，无脚本错误或看门狗超时。
- 14 项隐藏 WPF 设置控件检查首次通过，覆盖全局/独立动画与声音设置、有效参数、图像入口移除及 Beta 日志。不显示设置窗口。
- 主程序、动画宿主、启动器、语音工作进程 Release 编译通过。
- Portable 主程序使用新的独立空配置目录运行 `--background --no-startup --exit-after 1200`，启动与退出事件完整，退出码 0，无错误或崩溃。没有启动目标应用、展示设置或全屏动画。
- 测试环境中 WMI 进程事件订阅不可用，记录一条警告后按原设计使用 5 秒兼容轮询；本次没有修改监听系统。

本次仅验证指定前端/控件与 Portable 后台启动。没有重复原生全屏 WebView2 与真实目标客户端覆盖验收；历史运行限制见 V4.1 报告，不计入本轮通过项。

有效阶段实测（毫秒）：

- PARTICLE_RESIDUE → LOGO_ASSEMBLING：设置 350，实测 348。
- LOGO_ASSEMBLING → LOGO_HOLD：设置 850，实测 850。
- LOGO_HOLD → LOGO_BURST：设置 450，实测 450。
- LOGO_BURST → MULTIWINDOW_REVEAL：设置 900，实测 902。
- MULTIWINDOW_REVEAL → MULTIWINDOW_ACTIVE：设置 850，实测 854。
