# V4.6 Beta · 三项 Bug 修复

日期：2026-10-04。产品版本 `4.6.0-beta`，Windows 文件版本 `4.6.0.0`。

## 修复范围与原因

1. **粒子结束到 HUD 的空黑屏。** 没有发现需要删掉的固定 2000ms Timer。实际问题在原生准备画面：它在用户设定的粒子与交叉过渡时长结束后停止绘制内容，WebView2 若尚未准备完成，中间只剩清黑。只读查看的现场应用日志中，网页到约 4.35 秒才完成提交，与短参数下的空档吻合。修复让原生过渡层在原有粒子结束边界开始交叉显示原 HUD 首帧，网页接管前保持该帧；不添加、转移或延长时间参数。HUD 首帧由原始 APP_MARKUP、CSS 与 prepare() 构建，不另做布局。网页准备慢时，此缓存是静态初始 HUD；网页就绪后原有动态多窗口流程继续。没有新增后台预加载或额外等待阶段。

2. **启动画面异常闪烁。** 原生首帧窗口以前直接在屏幕 DC 上清黑并逐项绘制，每次刷新可能暴露中间的黑色清屏；提交给 WebView 时又把后备画面清黑。现在复用离屏缓冲绘制整帧，完成后一次提交，并在交接期间保留完整后备帧。缓冲和计时器随动画释放。网页根层本来没有周期性 blink/pulse，本轮不对粒子、550C 或 HUD 局部光标/LED 动画做全局禁用。原 Overlay 守卫、最终交接和 WebView 宿主代码未改动。

3. **“操作未完成”错误通知。** 现场日志中的重复 UiError 为 WPF NotSupportedException。定向调用真实 WPF ToolTipService 后复现：正常悬停问号时，ToolTip 的 StaysOpen=false 与自动提示机制冲突。去掉这个冲突属性，让 ToolTipService 正常管理打开与关闭。修复异常触发源，没有粗暴屏蔽所有异常；真实失败的日志、提示和“关于”诊断导出保持。

## 保持的行为

中央粒子三个时间参数、配置结构、全局/独立设置、粒子微动与图形算法、原始 550C、网页预加载、九个 HUD 窗口与布局、应用监听、快捷启动、声音和最终交接保持。更新日志新增 V4.6 Beta 的三条修复，其余历史正文保持。没有修改真实用户配置、目标客户端或关闭 ChatGPT/Codex。

## 最小必要验证

- **原生与帮助提示：17 项通过。** 以 500/1500/300ms、粒子打碎 500ms、多窗口交叉 100ms、倍率 0.75 复现短参数；HUD 在 1725ms 开始交叉、1800ms 完整出现。模拟 WebView 4400ms 才接管，连续 265 帧没有空黑帧。较晚时刻仍显示相同 HUD，没有把空档换成新 Timer。
- 既有 V4.5 待机初始、待机微动、重组和完整 550C 四张原生关键帧逐像素一致。五种现有 HUD 配色均能正确显示。原生后备层连续 12 次重绘保留完整帧，关闭后释放缓冲；重复关闭安全。
- 帮助提示旧属性组合明确复现 NotSupportedException；修复后连续 20 轮悬停、点击、关闭无异常。测试提示本体不可见，不弹桌面提示。
- **离屏网页：2 组通过。** 分别以原生已流逝 0ms 和 4400ms 接管，采样 1291/1169 帧，所有根层透明度保持 1，没有隐藏/显示循环或根层周期性动画。HUD 交叉开始后的首次可见采样分别约 11/10ms，之后透明度单调上升并保持。均完成 47 节点、9 个窗口及最终交接，脚本错误 0。这是本机离屏检查，不是外部显示器高速摄影数据。
- **Release：编译和发布成功。** 最终解决方案编译 0 警告、0 错误。没有执行无关的全项目测试。
- **Portable：隔离空配置后台启动/退出通过。** 退出码 0，没有 ERROR、崩溃、设置窗口、目标应用或全屏动画。环境中 WMI 不可用，原有检测备用路径正常启用，不弹错误通知。

首次原生 HUD 缓存比对发现边缘采样差异，定向诊断后对缓存图像关闭矢量抗锯齿、正确处理图像边缘，复测通过；粒子绘制参数保持。离屏网页检查首次通过后没有重复运行。Release 命令曾误向解决方案传入 RID，改为在项目发布时指定 RID 后编译通过；不涉及产品源码修改。

本轮全部使用内部、离屏与不可见提示测试，没有启动真实目标应用或全屏抢占桌面。证据见同目录 `native-test-v46-results.json`、`web-test-v46-results.json`、`portable-smoke-v46-results.json`、`images-v46/` 和 `release-verification-v46.json`。历史报告不代表本轮重新测试。
